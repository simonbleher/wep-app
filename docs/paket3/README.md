# Beta 3, Paket 3 – Eigene Positionen

Screenshots (erfundene Testdaten), erzeugt mit `npm run paket3:screenshots`.

| Bild | Zeigt |
|------|-------|
| `*-1-suche-liste` | Suche ohne Begriff: eigene Positionen vor dem Katalog |
| `*-2-suche-rasen-eigene-zuerst` | „Rasen“: eigene Position mit Kennzeichnung „Eigene“ steht vor dem gleich guten Katalogtreffer |
| `*-3-gemerkte-position-gewaehlt` | Gemerkte Position gewählt: Bezeichnung, Einheit, Preis vorbelegt |
| `*-4-freitext-merken` | Neue Freitext-Position mit Schalter „Als eigene Position merken“ (Standard an) |
| `*-5-profil-liste` | Profil → Eigene Positionen: Liste mit Ändern und Löschen |
| `*-6-profil-aendern` | Dialog „Eigene Position ändern“ |
| `*-7-profil-loeschen-rueckfrage` | Rückfrage vor dem Löschen |
