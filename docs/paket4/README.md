# Beta 3, Paket 4 – Fotos

Screenshots (erfundene Testdaten, selbst gemalte Testbilder), erzeugt mit `npm run paket4:screenshots`.
Die Bilder laufen durch die echte Foto-Verarbeitung der App (Verkleinern, Ausrichtung, Vorschau).

| Bild | Zeigt |
|------|-------|
| `*-1-fotos-leer` | Registerkarte „Fotos“ ohne Fotos: Gesamtansicht mit „Foto aufnehmen“ und „Aus Galerie“ |
| `*-2-fotos-gruppen` | Fotos zur Gesamtansicht und zu Positionen (Nummer wie im Export), Text unter der Vorschau |
| `*-3-grossansicht` | Großansicht mit Text zum Foto, Blättern, „Foto löschen“ |
| `*-4-foto-loeschen-rueckfrage` | Rückfrage vor dem Löschen |
| `*-5-position-mit-fotos` | „Position ändern“: Fotos dieser Position |
| `*-6-fotos-noch-nicht-geladen` | Fotos von einem anderen Gerät, die noch nicht auf diesem Gerät liegen |
| `*-7-export-fotos-zip` | Export ohne Konto: Fotos als ZIP neben der Excel-Datei |
